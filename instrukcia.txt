
# ИНСТРУКЦИЯ ПО НАСТРОЙКЕ И ИСПОЛЬЗОВАНИЮ "ТОНКО"

## НАСТРОЙКА БАЗЫ ДАННЫХ SUPABASE

База данных уже настроена со следующими таблицами:

1. **workshops** - мастерские
2. **employees** - сотрудники
3. **products** - изделия
4. **services** - услуги
5. **product_services** - связь между изделиями и услугами
6. **orders** - заказы
7. **order_logs** - логи заказов

Также создано хранилище (storage bucket) с названием "orders" для хранения фотографий заказов.

## ПОРЯДОК РАБОТЫ С ПРИЛОЖЕНИЕМ

### 1. Авторизация

При запуске приложения откроется страница авторизации, где необходимо:
- Выбрать имя сотрудника из выпадающего списка
- Выбрать адрес мастерской из выпадающего списка
- Нажать кнопку "Войти"

### 2. Оформление заказа

После авторизации вы попадаете на страницу оформления заказа:

- **Основная информация**:
  - Номер заказа: назначается автоматически при сохранении
  - Дата: по умолчанию текущая, можно изменить
  - Имя сотрудника: заполняется автоматически из авторизации
  - Мастерская: заполняется автоматически из авторизации
  - Имя клиента: необходимо заполнить
  - Телефон клиента: необходимо заполнить

- **Детали заказа**:
  - Приоритет: выберите из вариантов (Стандартный, Срочный, Не срочный)
  - Предварительная цена: укажите стоимость заказа
  - Дополнительная информация: добавьте комментарии к заказу

- **Изделия и услуги**:
  - Для каждого изделия (до 4-х):
    - Выберите тип изделия или "Другое" (появится поле для ввода)
    - Укажите вес изделия в граммах
    - Добавьте до 4-х услуг для данного изделия
    - Для каждой услуги выберите тип или "Другое" (появится поле для ввода)

- **Действия**:
  - "Печать": генерирует PDF-квитанцию заказа
  - "Сохранить": сохраняет данные заказа в базу

### 3. Таблица заказов

На странице "Таблица заказов" отображаются все сохраненные заказы:

- Можно фильтровать заказы по статусу, приоритету
- Поиск работает по номеру, дате, мастерской, имени клиента, телефону
- При клике на заказ появляются кнопки:
  - "Редактировать": позволяет изменить данные заказа
  - "Готово": меняет статус заказа на "completed" и добавляет запись в лог
  - "Выдано": меняет статус заказа на "issued" и добавляет запись в лог

### 4. Отчеты

На странице "Отчеты" отображается информация по выполненным заказам:
- Номер заказа
- Дата заказа
- Кто принял
- Кто выполнил
- Дата выполнения
- Кто выдал
- Дата выдачи

Данные можно экспортировать в Excel или PDF.

## ДОБАВЛЕНИЕ ПЕРВОГО ЗАКАЗА

1. Авторизуйтесь, выбрав имя сотрудника и адрес мастерской
2. На странице "Оформление заказа":
   - Заполните имя и телефон клиента
   - Выберите изделие (например, "Кольцо")
   - Укажите вес изделия
   - Добавьте услугу (например, "Полировка")
   - Укажите дополнительную информацию (если нужно)
   - Укажите предварительную цену
   - Выберите приоритет
   - Нажмите "Сохранить"

После сохранения заказ появится в таблице заказов, и вы сможете изменять его статус или редактировать информацию.

## ДОСТУП К ДАННЫМ В SUPABASE

Для просмотра и редактирования данных напрямую в Supabase:

1. Перейдите в панель управления Supabase
2. В разделе "Table Editor" выберите нужную таблицу
3. Используйте интерфейс для добавления, изменения или удаления данных

Для редактирования структуры таблиц используйте SQL Editor в Supabase.
